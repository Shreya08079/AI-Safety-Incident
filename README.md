## ✨ Welcome to the AI Safety Incident Dashboard

A beautifully designed, interactive dashboard for monitoring, reporting, and managing AI safety incidents. Built for clarity, speed, and a delightful user experience.

---

## 🌟 Features

- **Live Incident Feed**: Instantly see and filter AI safety incidents by severity and date.
- **Rich Visuals**: Glassmorphism, color-coded badges, and smooth animations for every interaction.
- **Smart Filtering & Sorting**: Effortlessly find what matters most.
- **One-Click Reporting**: Add new incidents with a gorgeous modal form and instant feedback.
- **Expandable Details**: Dive deep into each incident with animated, collapsible cards.
- **Responsive & Accessible**: Looks stunning on every device, keyboard and screen-reader friendly.
- **Download & Export**: Export incident reports with a single click.

# AI Safety Dashboard

A React-based dashboard for monitoring and managing AI safety incidents.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
```bash
npm install
```

### Running the Application

To start the development server:
```bash
npm start
```

The application will be available at `http://localhost:3000`

### Building for Production

To create a production build:
```bash
npm run build
```

## Features

- Real-time monitoring of AI safety incidents
- Incident reporting and tracking
- User authentication and authorization
- Interactive dashboard with data visualization

## Technologies Used

- React
- React Router
- Modern JavaScript (ES6+)
- CSS3
